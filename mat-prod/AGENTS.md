# MAT-PROD working rules

Scope: mat-prod/ and all descendants.

1. This directory is the canonical workspace for HORIZON-CL4-2027-01-MAT-PROD-61. Keep subsequent call work in this repository and directory.
2. Read README.md, current working files and relevant Git history before continuing. Preserve established decisions unless the user changes them or new evidence justifies reconsideration.
3. Preserve official templates byte-for-byte in 00_call/templates/. Create editable working copies under 01_proposal/.
4. Store proposal sources, consortium records, budget calculations, evidence, review responses and submission packages in their designated directories. Do not mix other calls into this directory.
5. Record substantive changes in Git with descriptive commits. Fetch and check the destination branch before writing; preserve unrelated files and concurrent work. Do not force-push.
6. Use UTF-8 Markdown for reviewable text where useful; keep required native formats alongside their source. Preserve official headings, tags and formatting when producing submission documents.
7. Distinguish verified facts, assumptions and unresolved items. Do not invent partners, results, TRL evidence, commitments or budgets.
8. Archive frozen submissions by date and version under 06_submission/. Updating this workspace does not authorize portal submission or messages to partners.
