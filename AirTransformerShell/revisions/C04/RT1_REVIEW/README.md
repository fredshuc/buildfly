# C04 RT-1 red-team review

Independent review of AirTransformerShell C04, the simplified two-bed, one-stage module with two adsorptive HX. It covers the shell, the M101 C04 HX, the R21 dampers at the C04 interfaces, the water changeover and cold-flow readiness.

- [C04_RT1_REVIEW.md](C04_RT1_REVIEW.md): dispositions, findings, cold-flow conditions and gates.
- [C04_RT1_FINDINGS.csv](C04_RT1_FINDINGS.csv): one row per finding, with file, part, state, result, criterion, smallest correction and closing evidence.
- [tools/](tools/): reproducible checks (CadQuery 2.8). Start with `run_all.sh`.
- [results/](results/): JSON outputs that every number in the review is taken from.

Status: review only. It does not change any delivered C04, HX, damper or hydronics file, and it is not a manufacturing release.
