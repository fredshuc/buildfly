# L1-SHELL → L2-B HX｜C11 充排水、凝结水与机械接口详化

任务号：AT-SHELL-C11-HX-T01-R1

目标：在H01四芯水平基线上，落实服务口、横装凝结水路径、密封/运动定位边界与真实连接条件。领取后连续执行。

## 1. 唯一基线与更改范围

父树：`fredshuc/buildfly@16b44e96c4640a4bccb565ae371fee445999634f`。本专业基线`HX/M101_C08_HORIZONTAL_H01/`，整机使用`AirTransformerShell/revisions/C10/`，配套HYD-S2和D04。四芯仍用同款无手性M101，保留Ø9.52级、39并联路×六程核心及四个安装变换。

八口均为向−X的Rp1¼端面，X=-787.5；77.5 mm可拆首段至X=-865。A床W1/W2的Y=-720/-570，B床145/295；下层Z560，上层Z895。冷下W1进入、热上W2进入的串联水向保持。

本轮先修改外围服务管、附件、局部密封/定位说明和连接堆栈；不通过移动四芯、改变层距/水口或回退历史热水方向解决接口问题。局部修改影响其他专业时，用接口差量单协调。

## 2. HX-01｜服务口按功能逐一收口（N4）

先建立28个功能端/原封口组的表：8个高点vent、8个H01新外引water drain、8组原header drain boss/closure、4个C05凝结水嘴。每组列介质、压力边界属性、零件名、安装坐标/方向、集气高点或集水低点依据、操作频率、处理方式和最终去向。

| 类别 | 当前依据 | 本轮优先路线 |
|---|---|---|
| 8个高点vent | 端面X=-456；帽包络X=-463…-449；下层Z706.35/816.35，上层1041.35/1151.35；位于机内，近板约17–19mm | 从实际集管高点用额定小管引至可操作湿区bulkhead，定义放气阀/接管、隔离和接水；保持无新增积气段 |
| 8个H01外引低点水排口 | 端面X=-698，下层Z531、上层866，已在湿侧；RT5帽到外皮膜约38.6–39.1mm | 定义实际阀/帽、软管/容器连接、操作和残液范围，不能只留cap代理 |
| 8组原header drain boss/closure | X603…618，近侧板约18–20mm | 由HX判定保留服务还是永久压力封闭；保留则给延管/检修路线；封闭则给压力边界工艺并证明替代排空/清洗路线 |
| 4个C05_SHORT_DRAIN_SPIGOT | X619…635，RT5该对象到所筛宿主为>80mm | 它是凝结水盘嘴，转入HX-02；不能混为水回路堵头 |

6–8mm外径可作为排气延管的初始候选，最终孔径、接头、压力额定、抗堵、允许流量和接管路线由实际功能确定。图纸应明确原高点到可操作端的连续路径、坡向及滞液/滞气口袋。

HX拥有从芯体压力边界到湿区bulkhead的服务管CAD和压力连接定义，供货边界包含bulkhead接头本体，以其湿区侧接合端面作为Hydronics交接界面。Hydronics拥有外侧操作阀、排放软管/终端及保护状态；Shell拥有安装板、穿壳气密/隔汽、结构支承、检修口和接水。三方共同冻结该端面的XYZ、轴向、连接规格、温压额定、拆接包络和安装反力；同一段管只建立一个受控模型。

若某处短延管不可行，可以采用可拆盖，但须交完整开盖、手/工具到达、转动施力、接水和复位顺序；不以“侧板可拆”文字代替包络。管线不得跨阻叶片扫掠或锁住芯体抽出。

充排液计划应对四芯逐一记录加水、放气、泄压、排水路径和残液量；六程回弯连通不能证明重力排空。本任务书不解除H01的live_water HOLD。首次注水/试压先明确压力、温度、隔离边界和停止条件；独立支承、实际连接额定与防拔、压力保护、可操作排气排水到位后，由HX与Hydronics联合签认、Shell确认安装条件，交L1限定范围放行。充排水及性能实测结果用于后续运行裁定。

## 3. HX-02｜核对并完成横装凝结水路径（L1-N7）

### 本次查明的源件功能

原C05包`source/build_c05.py::make_tray()`创建的是接水盘和`C05_SHORT_DRAIN_SPIGOT`，并把外接软管、穿底板、外部trap留给Shell。其盘面位于local XY，盘底local Z24–32、沿+Y落差8mm；排水嘴向local−Z。

H01变换为`(X,Y,Z)=(tx−z,ty−y,tz−x)`。因此旧盘近似转成全局YZ立面，旧嘴朝全局+X。此为源码/变换推导；本次未重建全机，不能据此直接断言机内没有其他收集件。**需要验证的是横装芯体的实际重力集水路径，不能默认旧盘旋转后功能仍成立。**

### 执行动作

1. 列出正常冷态、启动冷浸及环境露点超出局部表温时可能湿润的芯体/端部表面。按全局−Z标注液滴/水膜去向，核对两种风向下带水风险。
2. HX定义芯体边缘汇水、导流、滴落与可装附件接口；Shell完成机内收集、穿壳和外排水封。优先用外围可拆导流/收集件，保持核心与四芯位姿。
3. 不在两层有效空气通路中直接加整块实心接水盘。任何承接结构必须同时提供开放流通面积、压降/带水影响、清洁与抽芯路径。
4. 从湿表面到最终排水终点画出连续剖面。包括共床/分床汇流边界、风室压差隔离、检修拆接和无法自流的位置；不能以一个悬空spigot视作闭合。
5. 只有替代功能已明确、HX正式废止旧件且BOM/图纸更新一致时，才删除或封闭旧C05嘴。原文关于它为factory-sealed的假定不作为施工指令。

交付至少包括一张标全局Z的横装剖面、四芯凝结水功能表及Shell接收的排水接口。最终冷凝/排水效果通过受控湿态试验验证；当前先闭合设计路径。

## 4. HX-03｜面密封与运动的共同定位接口（F5/F7）

HX给出四芯定位基准、安装公差、允许热位移、局部边框不可侵入包络，以及20mm密封land的实际位置、平整度、允许压紧力/变形及不允许钻削区域。

Shell主责面密封、保持件、硬止挡和压紧载荷闭环；Dampers主责全程扫掠与端位。当前2mm面密封仅0.5–0.8mm工作行程，须由公差预算判断新截面。6–10mm闭孔条或球泡条作为候选，由压缩曲线、装配/热位移和漏风预算定型。

芯体承载/定位面和密封压缩硬止挡须独立于密封条自由厚度定义；四芯最终安装变换、八口位置和扫掠基准保持冻结。改密封截面时调整保持件/槽和压缩间隙，并核对夹紧变形及热滑动后的最坏芯位；确需移动定位面时提交L1接口变更。

上叶至`AIR_EDGE_0_1054`的1.2119mm必须以同一定位链计算最坏余量；HX提供边框尺寸和变形约束，不自行移动芯体。局部承接/封边改动须保持气流面积、结构与密封功能，并进入本专业BOM。

## 5. HX-04｜八首段连接与接管载荷

1. 将两端固定尾件、可缩中段、正锁止、防拔、密封、卡箍与螺栓落实为实际商品件或可制造定义。给温压额定、装配端距、最小啮合/搭接及动作余量，不以外形代理宣布承压成立。
2. 保留77.5mm与两固定端面，优先通过合适的实际薄工具/夹具、预装顺序或局部接头选择解决服务；必须证明施力和反扭矩路径。
3. 特别核对SW46尾件与SW50同时对扳现名义1.8mm轴向余量；SW50/SW53的15.6mm是另一组工具组合，不能互相替代。
4. 给八口允许力/弯矩或明确待供方确认的设计上限及依据。接受Hydronics支承后的六分量残余载荷，核对铜管、接头、集管与固定点；不能让水岛主重力落在HX口上。
5. 工具、保温拆罩、回缩、抬出及整芯抽出按真实步骤重验，带上新增vent/drain和排水连接，不把参考包络当装机硬件。

## 6. HX-05｜性能资料与签认清理

### 气侧

交涂层芯的Δp–v表/曲线，注明实测、供应商数据或计算；给涂层/干湿状态、两风向、有效面积、温湿度/密度和误差范围。无实测时交有来源的计算和采样方案，不能编造数据。RT5的60Pa/芯@2.21m/s为占位值，不据此定死布风板。

支持Shell保留C10屋顶、设置可拆布风件安装位和测孔，给无板/候选板的两芯串联阻力预算及测量接口。无需等待全CFD或实测完成才继续详图。

### 水侧

各芯均通过全床流量，两芯压降相加。提供热向W2→W1的部件适用/分配/排气依据和后续正反向验证计划；“没有单向元件”只证明拓扑，不证明两方向性能相同。

H01原0.678/0.497kPa为相关直管筛查，不能写成整床压降；更新服务管、接头后的名义含液量和局部阻力，未建模部分明确保留。

### 签认

更新`HX_SIGNOFF.json`及README：把八段P0改短、C10穿孔/座体让位、HYD-S2关闭FS/Q四交叉等已有证据对齐；不再把原1.65mm冠部空间或四交叉写成现状。保留尚未闭合的接头/压力保持、工具、排气排水、接管载荷和运行验证条件，每项写唯一owner和释放阶段。
