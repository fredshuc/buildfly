# L1-SHELL → L2-E HYDRONICS｜C11 水岛支承与水侧接口收口

签发：2026-11-07  
目标：在 HYD-S2 的现有水路布置上，补齐独立承重、真实接头与检修、穿墙防潮和可执行的通水条件。领取后连续执行，完成设计、自审及回件。

## 1. 输入和冻结边界

核读父树：`fredshuc/buildfly@16b44e96c4640a4bccb565ae371fee445999634f`。总成用 `AirTransformerShell/revisions/C10/`，本专业用 `hydronics/H01_HYD_S2/`；HX用 `HX/M101_C08_HORIZONTAL_H01/`，风阀用 `dampers/c09r1-d04/`。输入包散列见同包 `00_L1_DISPOSITION_AND_SEQUENCE_CN.md`。

保持 H01 八个水口及四芯位姿、X=-787.5端面、77.5 mm首段至X=-865；保持八只两通选择阀、每床FS/Q、两公共回水TA-Smart。冷水下芯→上芯，热水从上W2进入并逆向流过Q。保持现有主机外接方向和水岛总体位置。

HYD-S2 已关闭 FS/Q 四处交叉，不再为旧交叉重排水岛。水岛向−X伸出壳体约919 mm作为本轮原型占地输入。

## 2. HYD-01｜水岛独立支承，优先完成（N5）

### 设计动作

采用**连接主机底座/延伸滑橇的可拆水岛架**。L2-E拥有水岛架、管夹、支承横件/立件直至支架脚点的几何；L2-Shell拥有脚点以下的底座和主框连接，不重复建立另一套水岛架。

1. 给36个现有水岛发生项补真实承载管夹与支架；夹持面、保温承压块、螺栓和可调位置均入模。大阀、FS、Q及管道的主重力载荷由该架承担，不经八个HX口悬挂。
2. 先发脚点候选坐标、孔向、连接面、调节行程和六分量反力给Shell；继续完成自身详图。支架允许安装调整，使八个短节在无强迫对口状态下连接。
3. 定义固定、导向、滑动点，处理5–80°C水侧范围内的管道热伸长；冷侧夹具须防止保温压溃和金属贯穿热桥。
4. 对完整状态及拆去一根桥管、FS/Q、局部管夹后的维修状态给出稳定支承。先支住器件再释放连接；不得靠临时拉住铜管完成拆装。

### 计算与接受条件

- 质量表分干质量、实际含液量、额外操作/维修载荷；现有约24 L/床只是已建模库存加接头预算，不能当全水岛实测满液量。
- 覆盖满液静载、可达操作/维修力、热约束反力及适用接头压力推力；运输载荷与允许运输状态分列。压力推力按真实受压面积和约束关系建模，避免把每个闭合端的pA重复相加。
- 输出支架应力/挠度、脚点反力和八个HX口的残余Fx/Fy/Fz/Mx/My/Mz；与HX给出的允许载荷或本轮可接受上限核对。不是要求八口六分量全为零。
- 支架挠度及位置偏差进入接头、卡箍和抽出净距预算；运行态不碰撞只是基本条件。

## 3. HYD-02｜八处穿墙与上W2冠部热界面（N6，配合N1/N2）

### 已知边界

RT5记录：八处D35管经过Ø45内壁孔，名义径向空间仅5 mm；A角冠部最薄等效距离19.143 mm，至A柱2 mm。C10已为冠部让位，不能把HYD-S2旧让位清单再写成现存碰撞。A柱保持不切。

本轮暂以水5°C、空气32°C、露点26°C作局部校核/冷浸挑战点；这是L1本轮暂用条件，实际项目额定露点仍须在工况表标明出处。热端按HYD-S2的80°C边界核对材料和运动。

### 设计动作

1. 为八处穿墙逐点提供真实剖面：管、内壁、保温、隔汽层、套管/柔性唇、切缝、粘接面、允许位移、湿侧滴水出口。优先保持管心和现有孔位。
2. 对暴露干区给出无凝露的设计方案和表温裕量。只在指定可接水湿侧允许受控凝露，画出不经过电气、干风道、保温夹层的重力排水路线。
3. 隔汽套不能单独抬高薄层外表温度。若需增加局部保温厚度，提交给Shell的孔/套口差量、最小材料外包络及安装公差；Dampers核对Pin密封及运动，HX核对压力件。避免为5mm环隙问题直接切柱或破坏已接收座体。
4. 对两冠部给实际材料导热率、允许压缩、吸水/老化依据和表温核算。A柱附近倒角、金属热桥及口袋接缝按真实几何复核，不能以整圈圆筒结果冒充局部三维结论。
5. 输出与Shell自有口袋法兰连续接续的保温/隔汽端面；与外皮gland分开定义，以便各部件可更换。

### 计算与试验交付

提供8处穿墙和2处冠部的校核表，标明水温、空气温度、露点、k、表面对流边界、几何近似、表温和所需裕量。RT5完整组合给5mm表温16.18–20.41°C、19.143mm表温25.84–28.34°C，可用于重算对照，不能作为制造厚度或性能保证。

冷浸计划至少覆盖A柱角点、B口袋、最不利穿墙、外皮胶套/切缝和滴水接收；记录表温、环境露点、凝露位置、积水/滴水路径，稳态判据和接受条件写清。实测在样件可用后执行。

## 4. HYD-03｜真实接头、完整服务与通水条件

### 接头和服务

- FS采用现版Valworx配置与NPT1端；Q采用现版SM8020、G1平面密封接口。对选用的实际接头、垫片、可拆连接、螺纹啮合、接合后端距、压力/温度额定和防拔给出明确资料或待确认上限。
- Q每端50 mm是整栈装配预算，不是E40217单件30 mm长度。用真实接头更新端面和工具外径；不得把50 mm预算说成已验证实件值。
- 保留当前Q净直管329/174 mm及项目125 mm预算；若实际接头改变长度，重算双向要求与服务间隙。
- 新支架必须重新校核下W2→FS管到H01卡箍包络的原5.0 mm，以及A床FS到A_END_U抽出原9.3 mm。用最坏位置、挠度、工具和拆卸公差计算剩余量；余量须为正且实际工具可完成动作。
- 保留当前顺序：桥管拆除后，A床先Q后FS向−Y；B床先FS后Q向+Y。若优化1150 mm上提路径，可提供新的连续退出路径；1150 mm是原演示工位行程，不是机内通用净空。

### 联合签认与保护核对

与HX逐条更新现行条件签认：H01 `HX_SIGNOFF.json` 中“four FS/Q proxy intersections remain with L2-E”用HYD-S2+C10 RT5证据关闭，保留压力、接头保持、排气排水和实际运行尚未完成项。

在当前P&ID/状态表上逐项核对源侧卸载、压力许可、有符号Q、FS关闭后的两半床各自热膨胀/泄压路径、排气排水与各维修隔离状态。不能把阀座泄漏当作可靠泄压路径。缺项在本版补齐，引用已有内容时不重做整套架构。阀切换、实测Δp–Q、带液量和置换行为留为原型试验；43.1/43.2 s理想置换值不能直接成为控制定时。

总成最大允许压力PS不得超过适用温度下各实际压力件及连接允许压力中的最低值。允许温压范围、试验压力和试验条件分别列明；按适用方法与实际器件条件确定试验压力，不能将PS直接当作试验压力。缺供应商允许值时，标为未确认并给设计需求，不能自行宣称批准通水。
