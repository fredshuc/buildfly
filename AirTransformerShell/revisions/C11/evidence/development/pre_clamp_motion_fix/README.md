# Rejected upper-frame clamp arrangement

The earlier static S1/S2 endpoints were clear, but continuous motion found nine upper-blade/long-tie component collisions in total. Moving or thinning those upper jaws did not close the sweep. These reports and the old face-seal source preserve that failed iteration; they are not final acceptance evidence.

The final design replaces the upper long ties with bottom Y-end clamps and eight gusseted bearing extensions attached to the unchanged Shell RHS. No core or damper axis moves. Final evidence is in `evidence/bottom_clamp_export_check.json`, the current full assembly checks and `evidence/motion_delta.json`, each bound to the delivered STEP hash.

The local bracket/weld calculations remain conditional. HX frame capacity, real stock/weld fit, tolerance/thermal gaps and physical proof remain HOLD.
