# C06 RT-2 red-team review

Independent review of shell C06. C06 couples the C04 eight-channel distributor with M101 C04 (RT1 port alignment), eight D01 dampers at a 1280 mm bed pitch and the HYD-R1 water bay. It responds to the C04 RT-1 review.

- [C06_RT2_REVIEW.md](C06_RT2_REVIEW.md): disposition, the status of each RT-1 finding, new findings N1–N11, and the changes to the cold-flow plan.
- [C06_RT2_FINDINGS.csv](C06_RT2_FINDINGS.csv): one row per finding.
- [tools/](tools/): reproducible checks (CadQuery 2.8). Start with `run_all.sh`.
- [results/](results/): JSON outputs used in the review.

Status: review only. It does not change any delivered C06, HX, D01 or HYD-R1 file, and it is not a manufacturing release.
