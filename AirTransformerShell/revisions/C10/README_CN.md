# C10 四芯整机：H01 / D04 / HYD-S2 结构整合

本版接续本地 `codex/c10-four-core-prototype` 的 `918a444`，将三方最新交付接入同一套钣金模型。两个工况分别为 S1（A 工艺、B 再生）和 S2（A 再生、B 工艺）。**HYD-S2 是水路版本号，不是整机 S2 工况。**

这是整机几何与原型详设候选；钣金下料、结构承载和通水仍须各自放行。已完成的几何检查以 `evidence/verify_S1.json` 和 `verify_S2.json` 的实际结果为准。

## 打开顺序

1. `cad/C10_INSTALLED_S1.step` 或 `C10_INSTALLED_S2.step`：完整壳体、244 个 D04 风阀发生项、四枚 H01（共 2,204 个发生项）、72 个首段发生项、36 个 HYD-S2 水岛发生项。两态分别打开，不能重叠为同一运行状态。
2. `cad/C10_SHELL.step`：钣金/机架与密封保持组件；`C10_CHANGED_SHEET_AND_GLANDS.step` 仅列本轮变化。
3. `C10_STRUCTURE_REVIEW.png`：上风室、两个保温角部及外蒙皮压板的 STEP 剖面。
4. `cad/C10_SERVICE_AND_THERMAL_REFERENCE.step`：保温、工具和检修占位参考，不计作运行硬件。将它叠到对应工况检查，不能把检修包络算进 BOM。

## 钣金修改

### 八口外蒙皮与保持组件

按 H01 `HOST_CUT_PROPOSAL.csv` 在 X≈−650 的外蒙皮落实八个孔：W1 Ø120、W2 Ø94。内侧八处 Ø45 穿墙孔和 D04 上 W2 接续保留。外蒙皮孔心采用管路穿越截面，**不是**远端螺纹面坐标。

每床每层用一组双孔压板，包含两片 1.5 mm 钢压板（中缝 0.3 mm）、2 mm 安装厚度的柔性密封靴、六枚 M4 螺柱及螺母包络。密封靴的孔形从交付的湿舱保温体实际截面获得，贴外蒙皮而不夹紧铜管。压板 Ø4.5 孔位见 `GLAND_FIXINGS.csv`。螺纹和焊接细节为安装包络，不能当作供应商强度签认。

钢压板的管路避让孔为 Ø126/Ø100，比蒙皮孔各大 6 mm，以通过沿 −X 退出 12 mm 的连续扫掠；密封靴仍贴合保温体实际轮廓。验证保留螺柱和原湿舱保温，先拆螺母，再轴向退出压板解除螺柱保持。完整脱离保温/管路的最终上、下取出动作仍须无水试装确认。初版压板的 6.187 mm³ 退出擦碰记录保留在 `evidence/development_pass1/`，不作为最终放行结果。

安装次序：内侧保持/密封结构 → HX 与水平端管 → 保温 → 外蒙皮柔性靴 → 上下压板与螺母。柔性靴需留可现场封闭的服务切缝；几何表达的是封闭状态。拆管前卸压放水并拆相应保温及压板，割除/更新服务缝密封。材料、粘接、压缩量、扭矩、焊后平面度及热循环后的气密/隔汽须在实际板材和保温上验证。

### 上层 W2 保温角部

HYD-S2 保温冠部最高 Z1164.85，安装让位体最高 Z1166.85。C10 在两床进风底板与包边做局部抬高角部；屋面下表面 Z1168.5，上表面 Z1170，板厚 1.5 mm。后侧返边位于 X−584～−582.5，向风道内的返边分别到 A：Y−744、B：Y120。

原钢阀座承担前端封闭；新增屋面在其边界收口，不修改风阀零件、不留下裸露的贯通切口。`shell_changes.json` 逐件列出由既有阀座承担的封闭面。各钣金接缝需连续焊接/密封并验证正负压漏率。平面和接触几何不等于已经焊接。

**A 床立柱、补强 RHS 和四块连接腹板全部保留，不因保温让位而切削。** 水路在柱旁局部缩薄的保温仍需最大露点/最低水温试验；让位成功不能替代防结露验证。

### 上风室顶板与内侧板

保留后侧进风接口、反馈盖凹位和末端出口基准，抬高上风室在末端芯面区域的顶板，目标相对 C09 增加约 60 mm。新折线段采用法向 1.5 mm 板厚和相交斜接线；原后侧接口段保留。几何没有展开加工弯曲圆角，展开图需另补折弯半径和 K 因子。

内侧板同步加高到新顶板，闭合原 C09 抬高顶板后遗留的接缝错位；外侧板已有足够高度，保持既有反馈罩凹位。实际剖面、末端 100 mm 芯面上方高度及内侧板接缝误差见两态验证 JSON。几何加深是风量分布改进候选，**未进行 CFD，也未测得涂覆芯压降或风量均匀度**。

## 验证范围

- 从最终 S1/S2 STEP 全量读取，核对五组发生项、有效实体和全局定位。
- 全量跨组筛查壳体、风阀、四枚完整 HX、水岛与八个首段。正体积相交阈值 0.001 mm³；不以稀疏端管代理代替完整 HX。
- 新增/改动壳体对 D03 运动/服务、D04 局部检修、H01、HYD-S2 服务和冠部保温/让位体检查。工具按规定的检修动作使用，非要求所有工具同时入位。
- 新增/改动壳体之间及其对保留结构的重叠检查；历史接触逐对对照，不能把原有接触一律称作新碰撞，也不能把新增接触一律豁免。
- 实测上风室剖面和内侧板接缝，核对立柱保留及材料空间。

继承项仍包括：D03 下轴 1.0 mm 端隙、原上阀对 HX 的热态/公差余量，D04 密封材料与压片保持力，HX 面密封夹紧/压缩、整芯抽出顺序、排凝与存水弯，水件的额定值/接头防拔，独立水岛机架和管夹，以及 A 柱焊缝传力、框架刚度和搬运载荷。新壳体几何通过不能关闭这些条件。

`A_POST_WELD_REGISTER.csv` 给出保留补强件的连接边，供结构/焊接详设审签；本版未擅自指定工况载荷、焊缝许用应力或承载额定值。

## 从仓库重建

Python 3.12、CadQuery 2.8、OCP 7.9、NumPy；绘图还需 Matplotlib。运行依赖不入库。通过 `CADQUERY_LIBDIRS` 设置兼容安装目录（多个目录用系统路径分隔符连接），从任意目录运行：

```text
python source/prepare.py
python source/build.py
python source/verify.py S1
python source/verify.py S2
python source/measure_detail.py
python source/verify_service.py
python source/draw.py
python source/package.py
```

命令中的路径相对本 README 目录。受限 Windows 中如 WMI 系统元数据查询长时间等待，可为 CAD 进程设置 `C10_NO_WMI=1`，仅使该进程的 Python 元数据查询使用系统后备方式，不修改机器设置。`.work/` 为可重建缓存，不入库。
