## 两床的收口

坐标为全局毫米。后板外表面 X = −501.5，内表面 X = −500.0。上 W2 过板中心 Z = 1122.35；A 床 Y = −791.575，B 床 Y = 73.425。管外径 35，分体压圈外径 45；Pin 钢座与原静垫的让位为 R20.5。

| 接口 | D04 在 CAD 中的做法 | 两态 STEP 实测 |
|---|---|---|
| 两个半圈和管外壁 | 在后板外侧连续成形 1 mm 厚的膜，跨过两条分缝，沿管外壁形成 3 mm 长的软唇。静垫背面局部退 1 mm 接膜，其余厚度在该处为 2 mm。膜的常规外半径为 28 mm。 | 每床低 Y、高 Y 两个半圈的整个外端面各有 314.159 mm² 与膜相接；管外圆的接触面积为 329.867 mm²，对应完整一圈。 |
| A 床低 Y 外缘 | 压圈外缘至后板边缘仅 0.925 mm。膜填过后板与侧板的台阶，翻到外侧板上，沿 +X 搭接 8 mm，宽 34 mm。 | 侧板接触 272.000 mm²；后板接触 779.273 mm²；与静垫端部的搭接为 175.993 mm²。 |
| B 床顶部 | 压圈顶部 Z = 1144.85，Pin 开口下沿 Z = 1145.00。膜在原后板缺口处向 −X 加厚至钢阀座，并沿其余圆周搭到后板。 | 缺口投影 78.019 mm² 全部落在阀座钢面；后板接触 794.559 mm²；与静垫端部的搭接为 327.793 mm²。 |

**压圈保持。** 每床一件 2 mm 厚内挡片、一件 2 mm 厚可拆外压片。内片贴后板内面，装 HX 前在下端脚部连接后板。外片的 1 mm 台阶落在后板上，两枚外表面焊接 M4 螺柱和 AF7 防松螺母保持外片。螺柱位置为 Y = W2 中心 ±8，Z = 1086.85，建模突出 10 mm；外片孔径 4.5 mm。两片的开口都为 R20.5，每片都跨两半圈，每半圈的轴向保持投影面积为 27.928 mm²。压圈受两个方向的轴向载荷时，分别由外片经螺柱、内片经焊点传入后板。外片只压膜，不将刚性紧固件顶在铜管上。

上述接触量均取自名义装配面。膜按可割除、可重新成形的耗材设计，材料尚待选定。图中 1 mm 是安装厚度。还需在实际板材、涂层、铜管及静垫试片上验证粘接、撕裂和温度循环；在 1.5 mm 后板试片上确认焊点和螺柱的双向保持力、焊后平面度及紧固扭矩。

**拆装顺序。** 新件装前清理基面。先安装内挡片与外侧螺柱，再安装 HX、原分体压圈和 Pin 接口；让膜与管外壁、后板、静垫端部按详图连续接续，在材料规定的工艺窗口内成形、限厚和固化。检修时停机、卸压，用外径 11 mm 的套筒从 −X 侧操作两枚螺母，再将外压片沿 −X 抽 12 mm。更换压圈半片前需解除该床 Pin 钢座、静垫并割除旧膜。各半片先沿 −X 抽 2 mm 脱开后板，再分别沿低 Y、高 Y 方向移出 25 mm 脱离管径。换上新膜后复做密封检验。此顺序验证了局部释放段；整枚 HX 抽芯及 Pin 钢座上游拆装仍需整机检修签认。

**放行条件。** 用两床实物确认侧板翻边、B 床开口边、端部搭接的成形厚度，检查冷热位移后各钢件对管的剩余间隙。在项目规定的正、负压差下，对两条分缝、管周、A 翻边与 B 座端逐处做示踪检漏，记录压差和漏率，并在一次拆装、热循环后复测。漏率限值、试验压差、材料和焊接参数由整机与材料负责人签认。下轴端隙 1.0 mm、原上阀扫掠对 HX 最小余量 1.212 mm 仍属已有公差/热态问题；D04 的 19.893 mm 针对新密封附件。换向仍沿用 D03 的两风机卸载、两床端位反馈确认后再升载条件。

## 复算

环境为 Python 3.12、CadQuery 2.8 和 OCP 7.9。先从 C09R1 审核包取两态整机；另备 D03 原运动与检修 STEP，以及 S0 水路参考中的机外岛和检修 STEP。在本目录运行下列命令，两态分别传入 S1、S2。

```text
python source/build.py <C09R1两态所在目录> S1 S2
python source/verify.py S1 <D03_MOTION_AND_SERVICE.step>
python source/service.py S1 <C08_WATER_ISLAND_P0及C08_WATER_SERVICE_P0所在目录>
python source/c09_screen.py cad/D04_C09R1_INSTALLED_S1.step evidence/screen_S1.json
python source/drawing.py
```

build 记录给出输入和输出哈希，detail 记录给出最近点坐标与名义接触面积，screen 记录保留所有接触对，service 记录列出每步暂拆件、外部 P0 和整机检查结果。各项读数来自导出后重新打开的 STEP。P0 仅用作检修避让参照。八根水路首段、热水反向和整机风室由各自负责组审核。
